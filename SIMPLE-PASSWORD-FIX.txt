📋 OPTION 1: Password Yaad Hai? (Easiest)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open file: taskflow-app\backend\.env

2. Find:
   DATABASE_URL="postgresql://postgres:APNA_PASSWORD@localhost:5432/taskflow"

3. Replace APNA_PASSWORD with your real password

4. Example (if password is "admin123"):
   DATABASE_URL="postgresql://postgres:admin123@localhost:5432/taskflow"

5. Save file ✅

🔧 OPTION 2: Password Nahi Yaad? (Reset Karein)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

METHOD A: Using pgAdmin (GUI)
─────────────────────────────

1. Start Menu → Search "pgAdmin"
2. Open pgAdmin
3. Servers → PostgreSQL → Login/Group Roles → postgres
4. Right-click → Properties
5. Definition tab → Enter new password
6. Save

Use this password in .env file!


METHOD B: Command Line
─────────────────────────────

1. Open PowerShell as Administrator

2. Go to PostgreSQL bin:
   cd "C:\Program Files\PostgreSQL\15\bin"
   (Change 15 to your version)

3. Connect:
   .\psql.exe -U postgres

4. Try these passwords:
   - postgres
   - admin
   - password
   - (blank - just press Enter)

5. If connected, change password:
   ALTER USER postgres WITH PASSWORD 'newpass123';

6. Exit:
   \q

7. Use new password in .env:
   DATABASE_URL="postgresql://postgres:newpass123@localhost:5432/taskflow"
