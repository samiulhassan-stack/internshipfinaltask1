# ⚡ Quick Deploy Guide - 10 Minutes

## 🎯 Fastest Way to Deploy

---

## Step 1: Deploy Frontend to Vercel (5 minutes)

### 1.1 Go to Vercel
👉 **https://vercel.com/new**

### 1.2 Import Your Repo
1. Click **"Add New Project"**
2. Select **"Import Git Repository"**
3. Find: `samiulhassan-stack/internshipfinaltask1`
4. Click **"Import"**

### 1.3 Configure
```
Project Name: taskflow-frontend
Framework: Vite
Root Directory: frontend (Click Edit and select frontend folder)
Build Command: npm run build
Output Directory: dist
Install Command: npm install
```

### 1.4 Add Environment Variables
Click **"Environment Variables"** → Add these:

```
VITE_API_URL = https://your-backend-url.vercel.app/api
VITE_WS_URL = https://your-backend-url.vercel.app
```

**Note:** Use placeholder for now, update after backend deploy

### 1.5 Deploy!
Click **"Deploy"** → Wait 2 minutes → Done! ✅

You'll get: `https://taskflow-frontend-xyz.vercel.app`

---

## Step 2: Deploy Backend to Vercel (5 minutes)

### 2.1 Go to Vercel Again
👉 **https://vercel.com/new**

### 2.2 Import Same Repo
1. Click **"Add New Project"**
2. Select: `samiulhassan-stack/internshipfinaltask1`
3. Click **"Import"**

### 2.3 Configure
```
Project Name: taskflow-backend
Framework: Other
Root Directory: backend (Click Edit and select backend folder)
Build Command: npm install && npx prisma generate && npm run build
Output Directory: dist
Install Command: npm install
```

### 2.4 Add Environment Variables

**Option A: Use Vercel Postgres (Click "Create" next to DATABASE_URL)**
```
DATABASE_URL = [Auto-generated by Vercel Postgres]
JWT_SECRET = your-super-secret-jwt-key-change-in-production
NODE_ENV = production
FRONTEND_URL = https://taskflow-frontend-xyz.vercel.app
PORT = 3000
```

**Option B: Use Neon (Free External Database)**

1. Go to: https://neon.tech → Sign up
2. Create project: `taskflow-db`
3. Copy connection string
4. Use in Vercel:

```
DATABASE_URL = postgresql://user:pass@host.neon.tech/dbname?sslmode=require
JWT_SECRET = your-super-secret-jwt-key-change-in-production
NODE_ENV = production
FRONTEND_URL = https://taskflow-frontend-xyz.vercel.app
PORT = 3000
```

### 2.5 Deploy!
Click **"Deploy"** → Wait 3 minutes → Done! ✅

You'll get: `https://taskflow-backend-xyz.vercel.app`

## Step 3: Update Frontend Environment (1 minute)

1. Go to Vercel dashboard
2. Click on `taskflow-frontend` project
3. Go to **Settings** → **Environment Variables**
4. Update:
   ```
   VITE_API_URL = https://taskflow-backend-xyz.vercel.app/api
   VITE_WS_URL = https://taskflow-backend-xyz.vercel.app
   ```
5. Click **"Save"**
6. Go to **Deployments** tab
7. Click **"Redeploy"** on latest deployment

## ⚠️ Important Note: WebSocket Limitation

**Vercel serverless functions don't support persistent WebSocket connections.**

This means:
- ❌ Real-time updates won't work on Vercel
- ✅ All other features work perfectly

### Solution for Real-Time:

Deploy backend to **Railway** instead:

1. Go to: https://railway.app
2. Sign up with GitHub
3. New Project → Deploy from GitHub
4. Select: `samiulhassan-stack/internshipfinaltask1`
5. Root: `backend`
6. Add same environment variables
7. Done! Real-time will work! ✅
