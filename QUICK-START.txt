1. ✅ PostgreSQL install hai aur RUNNING hai
   → Windows Services check karein
   → "postgresql" service START honi chahiye

2. ✅ backend\.env file edit ki hai
   → Open: taskflow-app\backend\.env
   → DATABASE_URL mein apna PostgreSQL password daalna hai
   → Example:
     DATABASE_URL="postgresql://postgres:APNA_PASSWORD@localhost:5432/taskflow"

3. ✅ Database setup ho gaya hai (FIRST TIME ONLY)
   → Ye commands ek baar run karni hain:
     cd taskflow-app\backend
     npx prisma generate
     npx prisma migrate dev --name init
     npx prisma db seed

ERROR: "Cannot connect to database"
FIX: 
  1. PostgreSQL running hai? (services.msc check karein)
  2. Password sahi hai backend\.env mein?

ERROR: "Port 5000 already in use"
FIX:
  netstat -ano | findstr :5000
  taskkill /PID <PID> /F

ERROR: "Prisma Client not found"
FIX:
  cd taskflow-app\backend
  npx prisma generate

ERROR: Path with spaces issue
FIX:
  Folder ko C:\taskflow-app mein move karein
