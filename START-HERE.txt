✅ Git             → https://git-scm.com/downloads

┌─────────────────────────────────────────────────────────────┐
│ METHOD 1: DOCKER (EASIEST) ⭐ RECOMMENDED                    │
└─────────────────────────────────────────────────────────────┘

1. Open PowerShell in this folder
2. Run: docker-compose up -d
3. Run: docker-compose exec backend npx prisma migrate deploy
4. Run: docker-compose exec backend npx prisma db seed
5. Open: http://localhost:5173

   Login: admin@taskflow.com / demo123


┌─────────────────────────────────────────────────────────────┐
│ METHOD 2: WINDOWS BATCH FILES (EASY)                        │
└─────────────────────────────────────────────────────────────┘

1. Double-click: INSTALL.bat
2. Edit: backend\.env (add your PostgreSQL URL)
3. Double-click: START-WINDOWS.bat

   Login: admin@taskflow.com / demo123


┌─────────────────────────────────────────────────────────────┐
│ METHOD 3: MANUAL (FULL CONTROL)                             │
└─────────────────────────────────────────────────────────────┘

See START.md for detailed manual setup instructions.

🆘 NEED HELP?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: Can't connect to backend
Solution: Check http://localhost:5000/health works

Problem: Database connection failed
Solution: Verify PostgreSQL is running and DATABASE_URL is correct

Problem: Port already in use
Solution: Run: netstat -ano | findstr :5000
         Then: taskkill /PID <PID> /F

Full troubleshooting guide in START.md
