## 🚀 How to Run (For Reviewers)

### Quick Start (5 minutes)

1. **Clone Repository**
   ```bash
   git clone https://github.com/samiulhassan-stack/internshipfinaltask1.git
   cd internshipfinaltask1
   ```

2. **Backend Setup**
   ```bash
   cd backend
   npm install
   cp .env.example .env
   npx prisma generate
   npx prisma db push
   node setup-db.js
   npm run dev
   ```

3. **Frontend Setup** (new terminal)
   ```bash
   cd frontend
   npm install
   cp .env.example .env
   npm run dev
   ```

4. **Open Application**
   ```
   http://localhost:5173
   Login: admin@taskflow.com / demo123
   ```

### Docker Start (1 minute)
```bash
docker-compose up
```
